# Using tags

A tag is a free-form label on a Transaction. Where a Category answers "what kind
of spending is this" and every Transaction has exactly one, tags cut across
Categories and a Transaction can carry any number.

Reach for a tag when the grouping you want is not a kind of spending: one
holiday, one home project, everything you intend to claim back from an employer.
Those cross several Categories, and forcing them into the Category list distorts
every report that reads Category type.

## Tag a Transaction

Open the Transaction and find **Tags** in the drawer. Type a name and press Enter
or click **Add**. Remove one with the **×** on the tag chip.

Tags created this way are added to the Household's tag list automatically.

## Manage the tag list

**Settings → Tags** lists every tag with the number of Transactions carrying it,
which is the quickest way to spot a typo — "buisness" with one Transaction next
to "business" with forty.

- **New Tag** — a name and a colour from the preset swatches.
- **Edit** — rename or recolour. Renaming updates every Transaction at once.
- **Delete** — removes the tag from every Transaction that carries it. The
  Transactions themselves are untouched. This is not reversible, so check the
  count first.

## Tag automatically

A Rule can apply a tag as well as a Category — the **Add tag** action. If you tag
the same merchant by hand every month, write the Rule instead. See
[Categories](categories.md).

## Verify

- The tag chip shows on the Transaction.
- **Settings → Tags** shows the tag with the expected Transaction count.
- Renaming a tag changes it everywhere, without touching the Transactions.
