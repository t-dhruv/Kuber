# How-to: Use Tags for Organization

## Goal
Add flexible labels to txns for cross-cutting tracking (business, vacation, recurring).

---

## Add Tag to Transaction

1. **Transactions** → click txn
2. In drawer → type tag name (e.g., "business")
3. Press **Enter**
4. Save

Tag badge appears on txn.

---

## Filter by Tag

1. **Transactions** → open filter panel
2. Find **Tags** section
3. Select tag(s)
4. Apply filter

Only txns w/ those tags shown.

---

## Common Tag Ideas

| Tag | Use For |
|-----|---------|
| `business` | Tax-deductible expenses |
| `vacation` | Trip-related spending |
| `recurring` | Monthly subscriptions |
| `reimbursable` | Expenses you'll claim back |
| `gift` | Presents / donations |

---

## Bulk Tag

1. Check boxes → **Bulk Actions** bar appears
2. Select **Add Tag**
3. Type tag name → Enter
4. All selected txns get the tag

---

## Remove Tag

1. Open txn drawer
2. Click **×** on tag badge
3. Save

---

## Confirmation

- Tag badge visible on txn
- Filter by tag shows correct txns
- Bulk tag applies to all selected

## Troubleshooting

| Problem | Solution |
|----------|----------|
| **Tag not saving** | Press Enter after typing. Clicking away may not save. |
| **Can't filter by tag** | Check tag spelling. Filter is exact match. |
| **Too many tags** | Clean up in **Settings → Tags** (if available) or use categories for broad groups. |
