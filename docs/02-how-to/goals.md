# How-to: Set Savings Goals

## Goal
Create savings targets + watch progress rings fill up.

---

## Create Goal

1. Click **Goals** in sidebar
2. Click **Add Goal**
3. Fill:
   - **Name:** "Emergency Fund"
   - **Type:** savings (or vacation, home, wedding, education, car, other, debt)
   - **Target Amount:** `10000`
   - **Target Date:** optional (e.g., Dec 2026)
4. Click **Save**

Goal appears w/ progress ring.

---

## Track Progress

1. Go to **Goals**
2. Each goal shows:
   - **Progress ring** — percentage complete
   - **Current** vs **Target** amount
   - **Time remaining** (if target date set)

### Add Money to Goal

1. Click goal → **Add Contribution**
2. Enter amount: `500`
3. Save

Ring fills + current amount updates.

---

## Edit / Delete

- **Edit:** Click goal → edit details → Save
- **Delete:** Click trash icon → confirm

---

## View in Dashboard

Go to **Dashboard** → **Savings Goals** widget shows:
- All goals + progress rings
- Total saved vs total target
- Which goals need attention

---

## Tips

- **Emergency Fund:** 3-6 months of expenses
- **Vacation:** Set target date → auto-calculates monthly saving needed
- **Debt payoff:** Use type "debt" → track payments toward $0

---

## Confirmation

- Goal appears w/ correct target + date
- Progress ring updates after contributions
- Dashboard widget shows goal summary

## Troubleshooting

| Problem | Solution |
|----------|----------|
| **Goal type error** | Use lowercase: "savings" not "Savings". API expects lowercase enum. |
| **Progress not updating** | Contributions must be added manually. Kuber doesn't auto-detect yet. |
| **Goal not in dashboard** | Check **Dashboard → Customize** (if available) — widget may be hidden. |
